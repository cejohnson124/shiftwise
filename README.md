# Shiftwise

Smarter shifts, fewer headaches. Employees enter their own scheduling conflicts, and Shiftwise builds the week's schedule around them so managers save hours.

## The draft app
A single HTML file with no install. Data is saved in your browser only. Sign in by picking a name: **Alex** is the manager, the rest are employees. For a quick tour, sign in as Alex, open **Settings → Load demo week**, then **Generate schedule**.
